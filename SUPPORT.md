# Support

## Questions and usage help

Start with the [Agent Toolkit documentation](https://docs.epilot.io/agent-toolkit)
and the plugin-specific README in `plugins/epilot-developer/`.

For reproducible toolkit bugs or focused feature requests, open a GitHub issue
using the provided templates. Include the agent and version, operating system,
plugin version or commit, relevant sanitized configuration, and the smallest
reproduction you can provide.

For epilot account, organization, or production-platform support, use your
normal epilot support channel. Never post credentials, customer data, or private
organization configuration in a public issue.

Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md).
